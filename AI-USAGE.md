# AI Usage

I used **ChatGPT** during the project for understanding, reviewing and improving some parts of the work.

### How I used AI:

1. **Project understanding**
   I used ChatGPT to understand the project requirements and tasks in simple language.

2. **README.md**
   I used ChatGPT to improve and organize the README file.

3. **Frontend and Backend**
   I used ChatGPT for suggestions to improve some parts of the frontend and backend.

4. **Part A — Nginx**
   I used ChatGPT to understand and set up the `nginx/nginx.conf` file.

5. **Part A — Dockerfile**
   I used ChatGPT to understand how to add a non-root user (`appuser`) in the Dockerfile.

6. **Part B — HTTPS Links**
   I used ChatGPT to understand and troubleshoot the HTTPS links problem.

7. **Part B — Understanding the Problem**
   I used ChatGPT to understand the Part B problem statement and what was expected in the answer.

8. **Part D — Review File**
   I used ChatGPT to organize and format the `PART-D.md` file properly.

### Review and Corrections

I did not blindly use the AI output. I reviewed the suggestions, understood the changes, and corrected or rejected suggestions when they did not match the project requirements or my understanding.
